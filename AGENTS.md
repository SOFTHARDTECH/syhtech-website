# SYHTECH Website

Sitio web de SYHTECH, empresa de software factory y servicio técnico. El proyecto usa Astro.

## Desarrollo

- Mantener el sitio en español salvo que una tarea indique otro idioma.
- Priorizar una experiencia clara, profesional, accesible y responsive.
- Usar Astro como base; incorporar dependencias solo cuando aporten una necesidad concreta.
- Usar Tailwind CSS para los estilos siempre que sea posible, priorizando sus utilidades y tokens antes que crear CSS específico.
- Organizar las páginas en `src/pages/`, componentes reutilizables en `src/components/` y estilos o recursos según las convenciones de Astro.
- No editar `node_modules/` ni archivos generados.

## Verificación

- Tras cambios de código, ejecutar `npm run build` cuando el proyecto cuente con ese script.
- Conservar las modificaciones existentes del usuario y limitar los cambios al alcance solicitado.
